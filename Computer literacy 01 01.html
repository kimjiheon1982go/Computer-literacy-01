01

운영체제 (Windows 11)

2027년부터 필기 기준 운영체제가 Windows 11로 바뀝니다. 바로 가기 키, 파일 탐색기, 휴지통, 바로 가기 아이콘은 매회 출제되는 영역입니다.

운영체제의 개념과 Windows 11 특징

중요도 ★★☆

운영체제(OS)는 하드웨어와 사용자 사이에서 자원을 관리하고 인터페이스를 제공하는 시스템 소프트웨어입니다. 부팅 시 주기억장치(RAM)에 상주합니다.

운영체제 목적뜻
처리 능력 향상일정 시간 안에 처리하는 작업량 증가
응답 시간 단축작업 의뢰부터 결과를 받기까지 걸리는 시간 감소 (Turnaround Time)
사용 가능도 향상필요할 때 즉시 시스템 자원을 사용할 수 있는 정도
신뢰도 향상주어진 문제를 오류 없이 정확하게 해결하는 정도
  • 선점형 멀티태스킹: 운영체제가 CPU 사용 시간을 제어해, 한 프로그램이 멈춰도 다른 작업에 영향이 적습니다.
  • 플러그 앤 플레이(PnP): 하드웨어를 연결하면 자동으로 인식·설치합니다.
  • 64비트 전용: Windows 11은 32비트 버전이 없습니다. 설치 요건으로 TPM 2.0과 UEFI 보안 부팅이 필요합니다.
  • 스냅 레이아웃: 창 최대화 버튼에 마우스를 올리거나 Win+Z로 화면 분할 배치를 고릅니다.
  • 위젯, 가상 데스크톱, 클립보드 기록, 기본 백신 Microsoft Defender(Windows 보안)를 제공합니다.
  • 작업 표시줄 아이콘은 기본적으로 가운데 정렬입니다. 설정에서 왼쪽 정렬로 바꿀 수 있습니다.
처리 방식 정리일괄 처리(모아서 한 번에, 급여 계산) · 실시간 처리(즉시, 좌석 예약) · 시분할(시간을 쪼개 여러 사용자에게 번갈아 할당) · 다중 프로그래밍(여러 프로그램을 주기억에 올려 CPU 하나로 동시 실행처럼) · 다중 처리(CPU 여러 개) · 분산 처리(네트워크로 연결된 여러 컴퓨터가 나눠 처리)

휴지통과 바로 가기 아이콘

중요도 ★★★

휴지통은 삭제한 파일을 임시로 보관하며, 드라이브마다 따로 존재하고 크기도 드라이브별로 설정합니다. 휴지통 안의 파일은 실행하거나 편집할 수 없고, 복원해야 사용할 수 있습니다. 복원하면 원래 위치로 돌아갑니다.

휴지통에 들어가지 않고 바로 삭제되는 경우 Shift+Delete로 삭제 · USB 메모리, 네트워크 드라이브의 파일 삭제 · 휴지통 크기보다 큰 파일 삭제 · 휴지통 속성에서 '파일을 휴지통으로 이동하지 않고 바로 제거'를 선택한 경우 · 명령 프롬프트에서 del 명령으로 삭제
  • 바로 가기 아이콘은 원본 파일의 위치 정보만 가진 작은 파일입니다. 확장명은 .lnk이고, 아이콘 왼쪽 아래에 화살표가 붙습니다.
  • 바로 가기를 지워도 원본은 그대로입니다. 반대로 원본을 지우면 바로 가기는 실행되지 않습니다.
  • 원본 하나에 바로 가기를 여러 개 만들 수 있고, 폴더·드라이브·프린터에도 만들 수 있습니다.

중요도 ★★☆

  • 시작 메뉴: 고정됨 영역과 추천 영역으로 구성되고, '모든 앱'에서 설치된 앱 목록을 봅니다.

사용자 계정

중요도 ★★☆
  • 관리자: 모든 설정 변경, 프로그램 설치·제거, 다른 계정 관리가 가능합니다.
  • 표준 사용자: 일상 작업은 가능하지만, 시스템 전체에 영향을 주는 변경에는 관리자 암호가 필요합니다.
  • 사용자 계정 컨트롤(UAC): 프로그램이 관리자 권한이 필요한 변경을 할 때 확인 창을 띄워 무단 변경을 막습니다.
  • 로그인 방식: 암호, PIN, Windows Hello(얼굴·지문), 보안 키.

프린터 설정과 인쇄

중요도 ★★★
  • 기본 프린터는 한 대만 지정할 수 있고, 인쇄 시 프린터를 고르지 않으면 기본 프린터로 출력됩니다. 네트워크 프린터도 기본 프린터로 지정할 수 있습니다.
  • 인쇄 대기열에서 문서의 인쇄를 일시 중지, 다시 시작, 취소할 수 있습니다. 이미 인쇄가 시작된 문서도 취소할 수 있습니다.
  • 인쇄 중인 문서는 대기열에서 순서를 바꿀 수 없지만, 대기 중인 문서는 순서를 조정할 수 있습니다.
스풀(SPOOL) 함정스풀은 인쇄할 데이터를 디스크에 잠시 저장해 두고, 프린터가 처리하는 동안 CPU가 다른 작업을 하게 하는 기능입니다. 컴퓨터 전체의 작업 효율은 좋아지지만, 인쇄 속도 자체가 빨라지는 것은 아닙니다. 스풀을 쓰면 오히려 인쇄 시간은 조금 늘 수 있습니다.

PC 활용 및 유지보수

하드웨어, 소프트웨어, 자료 표현, 유지보수를 다룹니다. 1과목에서 가장 분량이 많고 기억장치·CPU 문제가 자주 나옵니다.

중요도 ★★☆

두 방식의 장점을 합친 것이 하이브리드 컴퓨터입니다. 세대별 소자: 1세대 진공관 → 2세대 트랜지스터 → 3세대 집적 회로(IC) → 4세대 고밀도 집적 회로(LSI) → 5세대 초고밀도 집적 회로(VLSI).

처리 능력 순: 슈퍼컴퓨터 > 메인프레임 > 미니컴퓨터 > 마이크로컴퓨터(PC). 휴대형으로 노트북, 태블릿, 웨어러블 기기가 있습니다.

중요도 ★★★

속도 순서: 레지스터 > 캐시 메모리 > 주기억 장치(RAM) > 보조 기억 장치(SSD > HDD). 용량은 반대 순서입니다.

  • HDD: 트랙(동심원) · 섹터(트랙을 나눈 최소 단위) · 실린더(같은 위치의 트랙 묶음) · 클러스터(파일 저장 단위). 접근 시간 = 탐색 시간 + 회전 지연 시간 + 전송 시간
  • SSD: 반도체 기반. HDD보다 빠르고 소음·발열·전력 소모가 적고 충격에 강합니다. 기계적 탐색이 없어 조각 모음이 필요 없습니다.
  • RAID: 여러 디스크를 하나처럼 사용합니다. RAID 0(스트라이핑, 속도↑, 안정성 없음) · RAID 1(미러링, 같은 데이터를 복제해 안정성↑).

1 물리전기 신호 전송허브, 리피터
  • 리피터: 약해진 신호를 증폭해 거리를 늘립니다.
  • 허브: 여러 컴퓨터를 하나로 묶는 집선 장치입니다.
  • 스위치: 목적지 MAC 주소를 보고 해당 포트로만 데이터를 보냅니다.
  • 라우터: 서로 다른 네트워크를 연결하고 최적 경로를 정합니다.
  • 게이트웨이: 프로토콜이 서로 다른 네트워크를 연결하는 출입구입니다.

TCP/IP 4계층: 네트워크 액세스 → 인터넷(IP, ARP, ICMP) → 전송(TCP, UDP) → 응용. TCP는 연결형으로 신뢰성 있게 전송하고, UDP는 비연결형으로 빠르지만 신뢰성이 낮습니다(실시간 방송, 게임).
