컴활 1급 스프레드시트 일반

01

스프레드시트 기본

데이터 입력 규칙, 채우기 핸들, 워크시트 관리가 나옵니다. 실기를 해 봤다면 쉽게 풀리지만, 보기 문장을 살짝 비튼 문제가 많습니다.

2027 개정2027년부터 엑셀 버전과 활용 방식이 바뀐 내용이 반영됩니다. 세부 버전은 공식 기준표로 확인하세요. 이 교재는 현재 시험 버전(MS Office 2021)에서 바뀌지 않는 기본 기능 위주로 정리했습니다.

  • 저장할 때 '일반 옵션'에서 열기 암호와 쓰기 암호를 따로 지정할 수 있습니다.

데이터 입력

중요도 ★★★
  • 숫자는 셀의 오른쪽, 문자는 왼쪽에 맞춰집니다. 숫자 앞에 작은따옴표(')를 붙이면 문자로 입력됩니다.
  • 날짜는 1900년 1월 1일을 1로 하는 일련번호로 저장되고, 시간은 하루를 1로 보는 소수로 저장됩니다. 예: 12:00 = 0.5
  • 분수는 앞에 0과 공백을 넣어 0 1/2처럼 입력합니다. 그냥 1/2을 입력하면 날짜(1월 2일)가 됩니다.
  • 숫자가 열 너비보다 길면 #### 또는 지수 형식으로 표시되고, 문자는 오른쪽 셀이 비어 있으면 넘쳐서 보입니다.

시트와 통합 문서 보호

중요도 ★★☆
  • 시트 보호: 셀 내용, 서식, 행·열 삽입 등을 수정하지 못하게 합니다. 셀 서식 › 보호 탭의 '잠금'이 해제된 셀만 보호 상태에서도 입력할 수 있습니다. '숨김'을 체크하면 수식이 수식 입력줄에 보이지 않습니다.
  • 통합 문서 보호: 시트의 구조(삽입, 삭제, 이름 바꾸기, 이동, 숨기기)를 바꾸지 못하게 합니다. 셀 내용은 수정할 수 있습니다.
  • 여러 시트를 그룹으로 선택하면 한 시트에 입력한 내용이 모든 시트에 같이 입력됩니다. 제목 표시줄에 '[그룹]'이 붙습니다.

셀 서식과 조건부 서식

사용자 지정 표시 형식의 결과를 묻는 문제가 거의 매회 나옵니다. 코드 기호의 의미를 정확히 외워야 합니다.

조건부 서식

중요도 ★★★
  • 조건에 맞는 셀에만 서식을 적용합니다. 규칙 종류: 셀 강조 규칙, 상위/하위 규칙, 데이터 막대, 색조, 아이콘 집합, 수식으로 지정.
  • 수식으로 행 전체를 칠할 때는 열만 고정합니다. 예: 범위 A2:E20을 선택하고 =$E2>=80
  • 수식은 반드시 =으로 시작하고, 결과가 TRUE인 셀에 서식이 적용됩니다.
  • 규칙이 여러 개면 위쪽 규칙이 우선이고, 규칙 관리자에서 순서를 바꿀 수 있습니다. 'true일 경우 중지'를 켜면 아래 규칙을 적용하지 않습니다.
  • 값이 바뀌면 서식도 자동으로 다시 적용됩니다.

표 서식과 셀 스타일

중요도 ★☆☆
  • 표(Ctrl+T)로 만들면 머리글에 필터 단추가 생기고, 행을 추가하면 서식과 수식이 자동으로 확장됩니다. 수식에서 표1[판매량] 같은 구조적 참조를 씁니다.
  • 표에서는 부분합을 쓸 수 없습니다. '범위로 변환'한 뒤 사용합니다.
  • 셀 스타일: 글꼴, 테두리, 채우기, 표시 형식을 묶어 이름을 붙여 둔 서식입니다.
  • 서식 복사: 홈 탭의 서식 복사 단추를 한 번 누르면 한 곳에, 두 번 누르면 여러 곳에 계속 붙일 수 있습니다. Esc로 끝냅니다.
03

수식과 참조

참조 방식, 이름 정의, 오류값은 함수 문제를 풀기 위한 바탕입니다.

셀 참조

중요도 ★★★
방식예복사하면
상대 참조A1행·열 모두 바뀜
절대 참조$A$1바뀌지 않음
혼합 참조$A1 / A$1열 고정 / 행 고정

F4를 누를 때마다 A1 → $A$1 → A$1 → $A1 → A1 순서로 바뀝니다.

  • 다른 시트: Sheet2!A1 · 시트 이름에 공백이 있으면 '1월 매출'!A1
  • 다른 통합 문서: [매출.xlsx]Sheet1!A1
  • 3차원 참조: 여러 시트의 같은 셀. =SUM(Sheet1:Sheet3!B2). SUM, AVERAGE, COUNT, MAX, MIN 같은 함수에서 쓸 수 있고 배열 수식에는 쓸 수 없습니다.
  • 순환 참조: 수식이 자기 자신의 셀을 참조하면 경고가 나옵니다.

이름 정의

중요도 ★★☆
  • 첫 글자는 문자, 밑줄(_), 역슬래시(\)만 가능합니다. 숫자로 시작할 수 없습니다.
  • 공백을 쓸 수 없고, A1이나 R1C1처럼 셀 주소 형태도 쓸 수 없습니다.
  • 대소문자를 구분하지 않으며 최대 255자입니다.
  • 이름은 기본적으로 절대 참조로 정의되고, 같은 범위(통합 문서 또는 시트) 안에서는 같은 이름을 두 번 쓸 수 없습니다.
  • 이름 상자에 직접 입력하거나 Ctrl+F3(이름 관리자)로 정의·수정·삭제합니다.

연산자와 오류값

중요도 ★★★

연산자 우선순위: 참조 연산자(: , 공백) → 음수(-) → % → ^ → * / → + - → &(텍스트 연결) → 비교 연산자(= < > <= >= <>)

참조 연산자: 콜론(:)은 범위, 쉼표(,)는 여러 범위를 합침, 공백은 두 범위가 겹치는 부분(교집합)입니다.

오류값원인
#DIV/0!0으로 나눔
#N/A찾는 값이 없음 (VLOOKUP, MATCH 등)
#NAME?함수 이름이나 정의된 이름을 잘못 입력
#NULL!공백(교집합)으로 지정한 두 범위가 겹치지 않음
#NUM!숫자가 잘못됨 (음수의 제곱근, 너무 큰 수)
#REF!참조한 셀이 삭제되어 참조가 잘못됨
#VALUE!숫자가 필요한 곳에 문자 등 잘못된 형식의 값 사용
#SPILL!동적 배열 결과가 들어갈 자리에 이미 값이 있음
####열 너비가 좁아 숫자를 다 표시하지 못함 (오류값은 아님)

배열 수식

중요도 ★★☆
  • 여러 값을 한 번에 계산하는 수식입니다. 예전 방식은 Ctrl+Shift+Enter로 입력하고, 수식 앞뒤에 { }가 자동으로 붙습니다. 중괄호를 직접 입력하면 안 됩니다.
  • 배열 상수: 열은 쉼표(,), 행은 세미콜론(;)으로 구분합니다. ={1,2,3;4,5,6}은 2행 3열입니다.
  • 조건별 합계: =SUM((A2:A10="영업")*(B2:B10)) · 조건별 개수: =SUM((A2:A10="영업")*1)
  • 배열 수식 범위의 일부 셀만 수정하거나 삭제할 수 없습니다.
  • 동적 배열(오피스 2021 이상): 결과가 옆 셀로 자동으로 펼쳐집니다(스필). FILTER, SORT, UNIQUE, SEQUENCE 함수가 여기에 속합니다.
04

함수

2과목에서 가장 많이 나오는 단원입니다. 함수의 인수 순서와 결과값을 정확히 기억하세요. 예시의 결과는 직접 계산해 확인한 값입니다.

수학 함수

중요도 ★★★
함수뜻예 → 결과
SUMIF(범위,조건,합계범위)조건에 맞는 값의 합계=SUMIF(A:A,"영업",C:C)
SUMIFS(합계범위,범위1,조건1,…)여러 조건의 합계. 합계 범위가 맨 앞=SUMIFS(C:C,A:A,"영업",B:B,">=30")
ROUND(수,자릿수)반올림ROUND(1234.567,1) → 1234.6
ROUND(수,음수)정수 부분에서 반올림ROUND(1234.567,-2) → 1200
ROUNDUP / ROUNDDOWN올림 / 내림ROUNDUP(3.21,1) → 3.3
INT(수)그 수보다 크지 않은 정수 (내림)INT(-3.7) → -4
TRUNC(수,자릿수)지정 자릿수 아래를 버림TRUNC(-3.7) → -3
MOD(수,나눌 수)나머지MOD(17,5) → 2
QUOTIENT(수,나눌 수)몫(정수)QUOTIENT(17,5) → 3

중요도 ★★★

차트

차트 종류별 특징과 추세선을 넣을 수 없는 차트가 자주 나옵니다.

차트 만들기와 구성 요소

중요도 ★★☆
  • F11: 기본 차트를 별도의 차트 시트에 만듭니다. Alt+F1: 현재 시트에 기본 차트를 만듭니다.
  • 원본 데이터를 바꾸면 차트에 자동으로 반영됩니다.
  • 숨긴 행·열의 데이터는 기본적으로 차트에 표시되지 않습니다. '숨겨진 셀/빈 셀' 설정에서 바꿀 수 있습니다.
  • 구성 요소: 차트 영역, 그림 영역, 차트 제목, 축(가로 항목 축, 세로 값 축), 축 제목, 범례, 데이터 계열, 데이터 레이블, 눈금선, 데이터 표.
  • 값 차이가 큰 계열은 보조 세로 축을 지정합니다. 막대와 꺾은선을 섞으면 콤보 차트입니다.
  • 차트 서식 파일(.crtx)로 저장해 다시 쓸 수 있습니다.

중요도 ★★★

  • 추세선을 넣을 수 없는 차트: 3차원, 누적형, 원형, 도넛형, 방사형, 표면형

06

데이터 관리와 분석

정렬 순서, 고급 필터 조건, 부분합, 피벗 테이블, 가상 분석이 나옵니다. 실기와 겹치는 부분이 많습니다.

정렬

중요도 ★★★
  • 정렬 기준은 최대 64개까지 지정할 수 있습니다.
  • 오름차순 순서: 숫자 → 문자 → 논리값(FALSE → TRUE) → 오류값 → 빈 셀. 문자는 특수 문자 → 영문 → 한글 순입니다.
  • 빈 셀은 오름차순이든 내림차순이든 항상 마지막에 놓입니다.
  • 기본은 위쪽에서 아래쪽(행 정렬)이고, 옵션에서 왼쪽에서 오른쪽(열 정렬)으로 바꿀 수 있습니다. 대소문자 구분도 옵션입니다.
  • 셀 색, 글꼴 색, 조건부 서식 아이콘을 기준으로도 정렬할 수 있습니다.
  • 사용자 지정 목록(예: 부장, 차장, 과장)의 순서로 정렬할 수 있습니다.
  • 숨겨진 행·열은 정렬에서 제외됩니다.

자동 필터와 고급 필터

중요도 ★★★
  • 자동 필터: 열마다 조건을 지정합니다. 서로 다른 열의 조건은 AND로 결합됩니다. 결과는 원래 위치에만 표시됩니다.
  • 필터로 숨긴 행은 인쇄되지 않고, 복사하면 보이는 셀만 복사됩니다.
  • 고급 필터: 조건을 워크시트에 따로 입력합니다. 결과를 다른 위치에 복사할 수 있고, '동일한 레코드는 하나만'으로 중복을 없앨 수 있습니다.

수식 조건조건 범위의 필드명을 원본에 없는 이름으로 쓰거나 비워 둠. 예: 필드명 '평균이상', 조건 =C2>AVERAGE($C$2:$C$20)

부분합과 데이터 통합

중요도 ★★★
  • 부분합은 그룹별 합계·평균·개수 등을 구합니다. 그룹 기준 필드로 먼저 정렬해야 제대로 묶입니다.
  • 부분합을 여러 번 겹쳐 쓰려면 '새로운 값으로 대치'를 해제합니다.
  • '그룹 사이에서 페이지 나누기', '데이터 아래에 요약 표시'를 선택할 수 있고, 모두 제거로 원래 상태로 돌아갑니다.
  • 왼쪽에 생기는 윤곽 기호(1, 2, 3)로 요약 수준을 바꿔 봅니다.
  • 데이터 통합은 여러 범위(다른 시트 포함)의 데이터를 하나로 모아 합계, 평균, 개수 등으로 계산합니다. '원본 데이터에 연결'을 선택하면 원본이 바뀔 때 결과가 따라 바뀝니다.

피벗 테이블

중요도 ★★★
  • 많은 데이터를 행, 열, 값, 필터 영역에 배치해 요약하는 대화형 표입니다.
  • 원본 데이터가 바뀌어도 자동으로 반영되지 않습니다. [새로 고침]을 해야 합니다.
  • 값 영역의 계산은 합계가 기본이고, 개수·평균·최댓값 등으로 바꿀 수 있습니다. '값 표시 형식'으로 비율(%)도 표시합니다.
  • 날짜·숫자 필드는 그룹화할 수 있습니다(월, 분기, 10단위 등).
  • 피벗 차트를 만들면 피벗 테이블도 함께 만들어지고, 피벗 테이블을 지우면 피벗 차트는 일반 차트가 됩니다.
  • 슬라이서와 시간 표시 막대로 필터를 단추처럼 씁니다.
  • 외부 데이터(Access, 텍스트 파일 등)를 원본으로 쓸 수 있습니다.

  • 데이터 유효성 검사: 입력할 수 있는 값(정수, 목록, 날짜, 텍스트 길이, 사용자 지정 수식)을 제한합니다. 목록은 쉼표로 구분해 입력합니다. 오류 메시지 스타일: 중지(입력 불가), 경고, 정보(입력은 가능).

매크로와 VBA

매크로 기록 대화상자 설정과 간단한 VBA 코드 해석이 나옵니다.

매크로 기록

중요도 ★★★
  • 매크로는 반복 작업을 기록해 한 번에 실행하는 기능으로, VBA 코드로 저장됩니다.
  • 이름: 첫 글자는 문자여야 하고, 공백과 대부분의 특수 문자는 쓸 수 없습니다(밑줄 _은 가능). 셀 주소와 같은 이름도 안 됩니다.
  • 바로 가기 키: Ctrl+영문자. 대문자로 지정하면 Ctrl+Shift+영문자가 됩니다. 숫자·특수 문자는 지정할 수 없습니다. 엑셀 기본 단축키와 겹치면 매크로가 우선합니다.
  • 저장 위치: 현재 통합 문서, 새 통합 문서, 개인용 매크로 통합 문서(PERSONAL.XLSB). 개인용은 엑셀을 실행할 때마다 모든 문서에서 쓸 수 있습니다.
  • 매크로가 있는 파일은 .xlsm으로 저장해야 합니다.
  • '상대 참조로 기록'을 켜면 셀 위치를 현재 셀 기준으로 기록합니다.
  • 매크로를 단추, 도형, 그림에 연결해 클릭으로 실행할 수 있습니다.

Sub 합계()
    Dim i As Integer, s As Integer
    For i = 1 To 10 Step 2
        s = s + i
    Next i
    If s >= 20 Then
        MsgBox "결과: " & s
    Else
        MsgBox "작음"
    End If
End Sub
i가 1, 3, 5, 7, 9일 때 더하므로 s = 25. 25 ≥ 20이므로 "결과: 25"가 표시됩니다.
